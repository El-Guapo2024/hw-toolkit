# Typed Core Spec

**Purpose:** lock the canonical data model first. Pydantic enforces every contract. Each entity converts to any target format (JSON, YAML, KiCad fields, SPICE deck, lcapy circuit, scikit-rf params, BOM CSV) via explicit serializers. No format is "the truth" — the pydantic model is.

This is the foundation everything else (injection, adapters, gates, library, skills) reads from. Get it right; everything else gets easier.

---

## Goals

1. **Well-typed everywhere.** No `dict` where structure is known. No `Any`. `Literal` / `Union` / `Enum` instead.
2. **Pydantic is the contract.** Validators catch semantic bugs (`vin > vout`, currents > 0, address uniqueness). No "trust the caller."
3. **Format-agnostic core.** The pydantic model knows nothing about KiCad / SPICE / CSV. Output formats are *derived views*, generated by explicit converter methods/functions.
4. **One-way: model → format.** Parsing format → model is a separate "input adapter," lives outside core.
5. **Versioned + migratable.** Every model carries `schema_version`. Migrations handle older shapes.
6. **CI-enforced.** mypy strict + pydantic strict mode + grep for forbidden imports. Drift becomes a build break.

---

## Ownership & mutation rules (the critical handoff contract)

Both agents must read from the pydantic contracts, but the contracts themselves are NOT runtime-editable. And the typed artifacts on disk have strict writer/reader assignments.

### The schema (`hw_agent/core/*.py` + this spec doc)

**Owners:** humans only, at design time via PR.
**Agents:** read via imported pydantic classes; **never** modify the class definitions, never edit `typed-core-spec.md`. Schema changes are design-time activities, not agent activities.

### The hard rules (PreToolUse hook enforces)

1. **`pcb-designer` cannot mutate research artifacts.** Write/Edit/MCP-mutation tools targeting `profile.md`, `n2_matrix.yaml`, `interfaces/`, `subsystems/`, `results/`, `baselines/research.yaml` are blocked when the active agent is `pcb-designer`.
2. **`researcher` cannot mutate KiCad/fab artifacts.** Write/Edit/MCP-mutation tools targeting `kicad/`, `fab/`, `baselines/fab.yaml` are blocked when the active agent is `researcher`.
3. **Neither agent edits the schema.** Write/Edit targeting `hw_agent/core/*.py` or `docs/investigations/typed-core-spec.md` is blocked when any agent is active. Schema changes happen via human PR.
4. **If `pcb-designer` finds a problem in research artifacts:** surface a structured error to the user; **do not edit**. User decides whether to re-invoke `researcher`.
5. **If `researcher` needs to revise a previously-locked baseline:** create a new baseline (`research-rev-B`) rather than editing the existing one. Baselines are immutable.

### Why this matters

Without these rules, agents silently fix each other's "mistakes" → corrupted handoffs, no audit trail, no way to know which agent introduced a bug. With these rules, every artifact has exactly one writer; any disagreement surfaces as an explicit user decision, not a silent overwrite.

The PreToolUse hook is the enforcement layer. The doctrine snippets remind the agent of the rule; the hook makes the rule unbreakable.

## Type-system principles

### No dict where structure is known
```python
# ❌ Today
actuals: dict = Field(default_factory=dict)

# ✅ Target
actuals: BuckActuals | LdoActuals | SensorActuals  # discriminated union
```

### No `Any`
```python
# ❌ extras: Any
# ✅ extras: dict[str, str | float | int | bool]   (or a typed Extras model per check)
```

### IDs are typed
```python
class SubsystemId(RootModel[str]):
    """Project-unique slug. Lowercase, snake_case, no spaces."""
    root: str = Field(pattern=r'^[a-z][a-z0-9_]*$', max_length=64)

class InterfaceId(RootModel[str]):
    root: str = Field(pattern=r'^[a-z][a-z0-9_]*$', max_length=64)

class MPN(RootModel[str]):
    root: str = Field(min_length=2, max_length=64)
```

Type-safe references prevent mixing a `SubsystemId` with an `InterfaceId` by accident.

### Units on quantities
Two acceptable patterns:

**A. Suffix-typed fields** (lightweight, what current model uses):
```python
class BuckRequirements(BaseModel):
    vin_v: float = Field(gt=0)             # volts in field name
    iout_a: float = Field(gt=0)            # amps
    fsw_khz: float = Field(gt=0)           # kHz
```

**B. Quantity wrapper** (stricter, more verbose):
```python
class Quantity(BaseModel):
    value: float
    units: Literal["V","A","W","Hz","ohm","F","H","degC","mm","mil"]

    @model_validator(mode='after')
    def positive(self):
        if self.value < 0 and self.units in ("V","A","Hz","F","H","ohm","mm","mil"):
            raise ValueError(f"{self.units} must be ≥ 0")
        return self
```

**Recommendation:** Pattern A by default (less ceremony, type-checker-friendly). Pattern B only for `EEResult.value` where units genuinely vary at runtime.

### Provenance as typed value, not dict
```python
ProvenanceSource = Literal[
    "measured", "datasheet", "dk", "jlc", "mouser",
    "user", "derived", "ai_estimated"
]
Confidence = Literal["low", "medium", "high"]

class ProvenanceTag(BaseModel):
    source: ProvenanceSource
    confidence: Confidence = "medium"
    note: str | None = None
    page: int | None = None                          # datasheet page
    fetched_at: datetime | None = None
    instrument: str | None = None                    # measured
    conditions: dict[str, float] | None = None       # measured
    chain: list[ProvenanceLink] = Field(default_factory=list)

class ProvenanceLink(BaseModel):
    source: ProvenanceSource
    note: str | None = None
    timestamp: datetime

class TrackedValue[T](BaseModel):
    """Wraps any value with provenance. Generic on the value type."""
    value: T
    provenance: ProvenanceTag
```

Every actual becomes `TrackedValue[float]` (or `[int]`, `[str]`). Provenance is unmissable.

### 1. `SubsystemTemplate` (library)
```python
class PortDef(BaseModel):
    name: str = Field(pattern=r'^[A-Z][A-Z0-9_]*$')
    type: Literal["power", "signal", "data", "mechanical"]
    direction: Literal["source", "sink", "bidirectional"]
    voltage_min_v: float | None = None
    voltage_max_v: float | None = None
    current_max_a: float | None = None
    required: bool = True

    @model_validator(mode='after')
    def voltage_order(self) -> "PortDef":
        if self.voltage_min_v is not None and self.voltage_max_v is not None:
            if self.voltage_min_v > self.voltage_max_v:
                raise ValueError(f"voltage_min > voltage_max on port {self.name}")
        return self

class CheckRule(BaseModel):
    id: str
    rung: Literal["lint", "cross_check", "analytic", "sim", "rules"]
    tool: str                                        # e.g. "ee.analytic.thermal_gate"
    inputs_from: list[str]                           # dotted paths into Subsystem
    pass_when: str | None = None                     # Python expr; default tool-specific
    severity: Literal["hard", "soft"]

class ReferenceDesign(BaseModel):
    mpn: MPN
    source: Literal["dk", "jlc", "mouser"]
    validated_in_project: str | None = None
    last_verified: date | None = None

class SubsystemTemplate(BaseModel):
    schema_version: Literal[1] = 1
    id: str = Field(pattern=r'^[a-z][a-z0-9_]*$')
    template_version: str = Field(pattern=r'^\d+\.\d+\.\d+$')  # semver
    name: str
    category: Literal[
        "power_conversion", "logic", "sensor", "actuator",
        "connector", "protection", "passive_cluster"
    ]
    ports: list[PortDef]
    default_requirements: dict[str, float | int | str]   # bounded shape per category — TODO refine
    typical_actuals_range: dict[str, dict[str, float]]   # field → {min, max, typical}
    check_rules: list[CheckRule]
    reference_designs: list[ReferenceDesign] = Field(default_factory=list)
    changelog: list[ChangelogEntry] = Field(default_factory=list)

class ChangelogEntry(BaseModel):
    version: str
    date: date
    change: str
```

### 2. `Subsystem` (project instance)
```python
class ChosenPart(BaseModel):
    lcsc: str | None = None
    mpn: MPN
    manufacturer: str
    package: str
    price_usd: float = Field(ge=0)
    price_tiers: dict[str, float] = Field(default_factory=dict)
    stock: int = Field(ge=0)
    datasheet_url: HttpUrl | None = None
    library_type: Literal["basic", "preferred", "extended"] = "extended"
    qty_per_board: int = Field(ge=1)
    notes: str = ""

class Decision(BaseModel):
    timestamp: datetime
    chosen: ChosenPart
    rejected: list[RejectedCandidate] = Field(default_factory=list)
    rationale: str = Field(min_length=20)            # force real explanation
    tradeoffs: list[str] = Field(default_factory=list)
    accepted_warnings: list[str] = Field(default_factory=list)
    alternate_lcsc: str | None = None
    requirements_snapshot: dict[str, float | int | str]

class RejectedCandidate(BaseModel):
    mpn: MPN
    lcsc: str | None = None
    reason: str = Field(min_length=10)

class PortBinding(BaseModel):
    port_name: str
    interface_id: InterfaceId | None = None          # null = unused (PG, EN on a buck w/o those)

class CalculationRef(BaseModel):
    check_id: str
    result_path: Path
    run_at: datetime
    passed: bool | None

class Subsystem(BaseModel):
    schema_version: Literal[1] = 1
    id: SubsystemId
    project: str
    template_id: str
    template_version: str                            # locked at creation
    category: str
    requirements: dict[str, TrackedValue[float | int | str]]   # narrow later per category
    actuals: dict[str, TrackedValue[float | int | str]]
    chosen_part: ChosenPart | None = None
    port_bindings: list[PortBinding] = Field(default_factory=list)
    calculations: list[CalculationRef] = Field(default_factory=list)
    decisions: list[Decision] = Field(default_factory=list)
    candidates_examined: list[ExaminedCandidate] = Field(default_factory=list)

    @model_validator(mode='after')
    def chosen_has_decision(self) -> "Subsystem":
        if self.chosen_part and not self.decisions:
            raise ValueError("chosen_part set but no Decision recorded")
        return self
```

### 3. `InterfaceRecord`
```python
class InterfaceParticipant(BaseModel):
    subsystem_id: SubsystemId
    port_name: str
    role: Literal["source", "sink", "controller", "target", "peer"]
    address: str | None = None                       # I²C addr, CAN id, etc.

class ElectricalSpec(BaseModel):
    voltage_nominal_v: float = Field(gt=0)
    voltage_tolerance_pct: float = Field(ge=0, le=100)
    current_continuous_max_a: float = Field(gt=0)
    current_peak_max_a: float = Field(gt=0)
    ripple_max_mv: float | None = Field(default=None, ge=0)

    @model_validator(mode='after')
    def peak_ge_continuous(self) -> "ElectricalSpec":
        if self.current_peak_max_a < self.current_continuous_max_a:
            raise ValueError("current_peak < current_continuous — physically impossible")
        return self

class ProtocolSpec(BaseModel):
    name: Literal["i2c", "spi", "uart", "can", "usb", "ethernet", "swd"]
    speed_hz: int | None = None
    pullup_ohm: int | None = None
    voltage_v: float | None = None

class Constraint(BaseModel):
    id: str
    rule: str                                        # Python expr against InterfaceRecord + participants
    severity: Literal["hard", "soft"] = "hard"

class InterfaceRecord(BaseModel):
    schema_version: Literal[1] = 1
    id: InterfaceId
    project: str
    type: Literal["power", "signal", "data", "mechanical"]
    direction: Literal["source_to_sink", "bidirectional", "broadcast"]
    template_id: str | None = None
    participants: list[InterfaceParticipant] = Field(min_length=2)
    electrical: ElectricalSpec | None = None         # power interfaces
    protocol: ProtocolSpec | None = None             # signal/data interfaces
    constraints: list[Constraint] = Field(default_factory=list)
    owner: Literal["spec", "designer", "user"]
    created: datetime
    notes: str = ""

    @model_validator(mode='after')
    def power_has_electrical(self) -> "InterfaceRecord":
        if self.type == "power" and self.electrical is None:
            raise ValueError("power interface must have electrical spec")
        if self.type in ("signal", "data") and self.protocol is None:
            raise ValueError(f"{self.type} interface must have protocol spec")
        return self
```

### 4. `N2Matrix`
```python
class N2Node(BaseModel):
    id: str
    type: Literal["external", "subsystem"]
    count: int = 1

class N2Edge(BaseModel):
    from_node: str = Field(alias="from")
    to_node: str = Field(alias="to")
    interface_id: InterfaceId

class N2Matrix(BaseModel):
    schema_version: Literal[1] = 1
    project: str
    nodes: list[N2Node] = Field(min_length=1)
    edges: list[N2Edge] = Field(default_factory=list)

    @model_validator(mode='after')
    def edges_reference_nodes(self) -> "N2Matrix":
        node_ids = {n.id for n in self.nodes}
        for e in self.edges:
            if e.from_node not in node_ids:
                raise ValueError(f"edge.from {e.from_node} not in nodes")
            if e.to_node not in node_ids:
                raise ValueError(f"edge.to {e.to_node} not in nodes")
        return self
```

## Validators — semantic invariants beyond types

Pydantic catches type bugs; validators catch *physical* bugs. Examples per entity:

| entity | invariant | enforcement |
|---|---|---|
| `Subsystem` (buck) | `requirements.vin > requirements.vout` | model_validator |
| `Subsystem` (LDO) | `requirements.vin >= requirements.vout + actuals.vdropout` | model_validator |
| `ElectricalSpec` | `current_peak ≥ current_continuous` | shown above |
| `InterfaceRecord` (i2c) | participants[].address unique on bus | model_validator |
| `N2Matrix` | all edge endpoints exist in nodes | shown above |
| `PortDef` | voltage_min ≤ voltage_max | shown above |
| `Decision` | rationale ≥ 20 chars | Field(min_length=20) |
| `EEResult` | if passed=True/False, margin must be set | model_validator |
| `Subsystem` | chosen_part set ⇒ decisions non-empty | shown above |
| `InterfaceRecord` | power type ⇒ electrical set; signal type ⇒ protocol set | shown above |

These are the bugs Pydantic-strict catches BEFORE any check runs. Cheapest validation rung in the ladder.

### SPICE netlist segment
```python
def subsystem_to_spice_segment(sub: Subsystem) -> str:
    """Emit a .subckt block for ngspice."""
    if sub.category != "power_conversion":
        return ""                                    # only power has SPICE relevance for now
    lines = [f".subckt {sub.id.root} VIN VOUT GND"]
    a = {k: v.value for k, v in sub.actuals.items()}
    lines.append(f"L1 VIN sw {a['L_uH']}u")
    lines.append(f"C1 VOUT GND {a['Cout_uF']}u")
    lines.append(f".ends {sub.id.root}")
    return "\n".join(lines)
```

### lcapy circuit
```python
def subsystem_to_lcapy(sub: Subsystem) -> str:
    """Emit lcapy netlist string."""
    a = {k: v.value for k, v in sub.actuals.items()}
    r = {k: v.value if hasattr(v, 'value') else v for k, v in sub.requirements.items()}
    return f"""
L1 1 2 {a['L_uH']}e-6
C1 2 0 {a['Cout_uF']}e-6
R1 2 0 {r['vout']/r['iout_typical']}
V1 1 0 ac {r['vin']}
"""
```

### Pattern
Every converter:
- takes a pydantic model (or specific field) → returns a string / dict / bytes
- lives in `hw_agent/core/converters/<format>.py`
- has tests with golden outputs
- never goes the other direction

**Input parsing** (e.g. reading a KiCad symbol field back into a `ChosenPart`) is a separate concern in `hw_agent/core/parsers/<format>.py` — different module, different tests, different failure modes.

## Schema versioning + migration

Every model has `schema_version: Literal[1] = 1`. When breaking change needed:

1. Bump literal in code: `schema_version: Literal[2] = 2`.
2. Add a migration function: `hw_agent/core/migrations/v1_to_v2.py` — takes v1 dict, returns v2 dict.
3. Add a custom `__init_subclass__` or pre-validator that detects `schema_version: 1` and migrates before validation.
4. Old files keep working; on next save they upgrade.

```python
@field_validator('schema_version', mode='before')
@classmethod
def migrate(cls, v, info: ValidationInfo):
    if v == 1 and cls.__name__ == "Subsystem":
        # migration logic if needed before this validator returns the new version
        from hw_agent.core.migrations import v1_to_v2_subsystem
        info.data.update(v1_to_v2_subsystem(info.data))
        return 2
    return v
```

Migration tests live in `tests/test_migration.py` — golden v1 → expected v2.

## Pydantic strict mode + mypy

Both layers of enforcement:

**Pydantic strict mode** — refuses coercion:
```python
class Subsystem(BaseModel):
    model_config = ConfigDict(strict=True, extra='forbid', frozen=False)
```
- `strict=True` — no "5.0" → 5 coercion. Real ValidationError on type mismatch.
- `extra='forbid'` — unknown fields rejected. Schema drift becomes visible.
- `frozen=False` — mutable (we update actuals, append decisions). Set `True` on `EEResult`, `Decision`, `Baseline` (immutable records).

**mypy strict** — static check before runtime:
```ini
# pyproject.toml [tool.mypy]
strict = true
plugins = ["pydantic.mypy"]
warn_unused_ignores = true
disallow_any_explicit = true
```

`disallow_any_explicit = true` catches any `Any` annotation in our code. Pydantic plugin teaches mypy about model fields.

CI runs mypy → fails on any error. Promotes "well-typed" from aspiration to invariant.
